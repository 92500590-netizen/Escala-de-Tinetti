# Escala-de-Tinetti

Herramienta clínica para registrar la evaluación de equilibrio y marcha en personas mayores con la escala de Tinetti (POMA).

## Uso

Abre `index.html` en un navegador. No requiere instalación y los datos de la evaluación no se guardan ni se envían. Puedes imprimir el resultado desde la misma página.

La evaluación contiene 9 pruebas de equilibrio (máximo 16 puntos) y 7 de marcha (máximo 12 puntos). Algunas pruebas se muestran como criterios puntuables separados. Las categorías orientativas son: menos de 19, riesgo alto; 19-23, moderado; 24-28, bajo.

Esta herramienta es un apoyo para profesionales capacitados y no sustituye el juicio clínico ni una valoración integral del riesgo de caídas.
